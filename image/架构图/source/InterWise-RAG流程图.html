三、观测与复盘：候选、消费、落库三类事实分开记录

RAG 请求 / 候选日志

query、策略、延迟、零命中、分数、排序、是否选入上下文；规划后即可能存在。

会话消费

成功生成后写入 usedAtomIds，用于本场后续排重；补救上下文不消费。

已落库轮次证据

结构化 interview_turn 保存 promptAtomIds；岗位覆盖统计知识暴露，不等于掌握。

并列复盘消费者

异步详细报告读取轮次与 RAG 快照；AI Mentor 按 userId + positionId 独立聚合。

正式检索门禁：status=PUBLISHED + publication_status=PUBLISHED + review_status=PASS + vector_status=SYNCED，并且公共 / 私有 owner、岗位和知识库作用域全部匹配。MySQL 是业务真相，Qdrant 是可重建索引。
