## 贡献指南

### 贡献流程

1. Fork 本仓库到你的 GitHub 账号。
2. 将仓库克隆到本地：

   ```bash
   git clone https://github.com/你的用户名/项目名.git
   cd 项目名
````

3. 创建新的开发分支：

   ```bash
   git checkout -b feature/your-feature-name
   ```

4. 完成代码修改，并确保项目可以正常运行。

5. 提交你的修改：

   ```bash
   git add .
   git commit -m "feat: add your feature"
   ```

6. 推送分支到你的远程仓库：

   ```bash
   git push origin feature/your-feature-name
   ```

7. 在 GitHub 上发起 Pull Request，目标分支请选择本项目的 `main` 分支。

8. 等待维护者 Review。如有修改建议，请根据反馈继续更新你的分支。

### 提交信息规范

建议使用清晰、简洁的提交信息，例如：

```bash
feat: add login page
fix: resolve navbar display issue
docs: update README contribution guide
refactor: improve user service structure
```

常用前缀说明：

* `feat`: 新功能
* `fix`: 修复问题
* `docs`: 文档修改
* `style`: 代码格式调整，不影响逻辑
* `refactor`: 代码重构
* `test`: 测试相关修改
* `chore`: 构建、配置或其他杂项修改

### Pull Request 要求

提交 PR 前，请确认：

* 代码可以正常运行；
* 没有提交无关文件；
* 命名清晰，代码风格尽量与项目保持一致；
* 如修改了功能，请补充必要的说明或测试；
* PR 描述中请简要说明本次修改的内容和原因。

### Issue 反馈

如果你发现 Bug、希望新增功能，或对项目有改进建议，欢迎提交 Issue。请尽量说明：

* 问题或建议的具体内容；
* 复现步骤，如果是 Bug；
* 期望的结果；
* 相关截图或错误日志，如有。

感谢你的贡献！
